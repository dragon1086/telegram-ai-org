## 완료 보고 체크리스트 (필수 7개 항목)

작업 완료 선언 전 아래 항목을 **전부 체크**해야 한다.

```
[ ] 1. 파일 경로 확인
       → 실제 절대경로 명시 (예: /Users/rocky/telegram-ai-org/logs/experiment_log.yaml)

[ ] 2. 파일 존재 여부 확인
       → ls -la 또는 Glob으로 확인 후 존재 여부 명시

[ ] 3. 항목 수 카운트
       → "총 X개 항목" 형태로 수치 명시

[ ] 4. 필드값 전수 검증
       → 각 항목별 필드 적용 여부를 표 형태로 열거
       → "적용: X개 / 미적용: Y개" 형태로 수치 명시

[ ] 5. 실제 파일 내용 발췌본 첨부
       → 핵심 필드 포함 YAML/JSON 블록을 최소 2~3개 항목 직접 인용

[ ] 6. 미적용/예외 항목 명시
       → 미적용 항목이 0개여도 "미적용 항목: 0개" 명시

[ ] 7. 완료 기준 대비 달성 여부 표
       → 요구사항 원문 vs 실제 완료 내용을 1:1 대응 표로 작성
```

---

## 체크리스트 미충족 시 처리 원칙

- 7개 항목 중 하나라도 미충족 → 완료 선언 불가
- "부분 완료"인 경우: 완료/미완료 항목을 분리하여 보고
- 파일 미생성 상태라면: 즉시 생성 후 체크리스트 재실행
