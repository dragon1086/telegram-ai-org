## 5. 자동화 이후 예외 에스컬레이션 프로세스

자동화된 체크가 실패하거나 판단 불가 상황 발생 시 아래 절차를 따른다.

```
자동화 체크 실패 발생
        │
        ▼
실패 유형 분류 (자동)
        │
   ┌────┴────────────┐
   ▼                  ▼
KNOWN 패턴          UNKNOWN / 신규 패턴
(기존 룰 매칭)       (룰 미매칭)
   │                  │
   ▼                  ▼
자동 재시도         기획실 알림
(최대 3회)          (Slack/텔레그램)
   │                  │
실패 지속            ▼
   │            기획실 + 해당 부서
   ▼            15분 내 1차 판단
운영실 알림          │
(즉시)          ┌────┴────────┐
                ▼              ▼
           스펙 이슈       인프라 이슈
           기획실 처리     운영실 처리
```

### 에스컬레이션 SLA

| 단계 | 대상 | 응답 시간 |
|------|------|-----------|
| L1: 자동 재시도 | 시스템 | 즉시 (3회, 30초 간격) |
| L2: 담당 부서 알림 | 개발실/운영실/디자인실 | 5분 이내 |
| L3: 기획실 판단 요청 | 기획실 | 15분 이내 |
| L4: 총괄 PM 보고 | 총괄 PM | 30분 이내 (L3 미해결 시) |

## 6. 자동화 완료 후 검증 기준

- 수동 확인 포인트 10개 중 **7개 이상** 완전 자동화 (H-01~H-08, H-10)
- 사람이 판단해야 하는 항목(H-04, H-09)의 **판단 소요 시간** ≤ 2분/건 (기준 표 활용)
- CI 파이프라인에서 pre-flight 실패 시 **자동 중단 + 알림** 100% 작동
- 에스컬레이션 L2 응답률 **95% 이상** (5분 이내)
