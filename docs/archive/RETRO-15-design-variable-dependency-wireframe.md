## 2. 와이어프레임 패턴 A: 변수 의존성 DAG 다이어그램

> 개발실·운영실 공통 활용. 코드 배포 전 "어떤 변수가 교차 가능한가"를 시각 확인.

### 2-A. 레이아웃 구조

```
┌─────────────────────────────────────────────────────────┐
│  🔍 변수 교차 의존성 맵  [v1.2 기준]          [새로고침] │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   [infra_baseline]──┐                                   │
│         │           ├──▶ [렌더링 결과]──▶ [E2E 로그]   │
│   [font_family]─────┤                                   │
│         │           │                                   │
│   [theme_mode]──────┘                                   │
│                                                         │
│   🔴 High-risk 교차: 3개   🟡 Medium: 9개   🟢 Low: 9개│
├─────────────────────────────────────────────────────────┤
│  [교차 상세 보기]   [체크리스트 실행]   [로그 내보내기] │
└─────────────────────────────────────────────────────────┘
```

### 2-B. 노드별 색상 코딩 (WCAG AA 준수)

| 위험도 | 색상 HEX | 대비비 (배경 대비) | 아이콘 (색상 보조) |
|--------|----------|-------------------|-------------------|
| 🔴 High | `#DC2626` | 5.2:1 (AA ✅) | ⚠ 경고 아이콘 |
| 🟡 Medium | `#D97706` | 4.6:1 (AA ✅) | ⚡ 주의 아이콘 |
| 🟢 Low | `#16A34A` | 4.7:1 (AA ✅) | ✓ 정상 아이콘 |

> **접근성 원칙**: 색상만으로 위험도를 구분하지 않음. 반드시 아이콘·텍스트 라벨 병용.

### 2-C. 인터랙션 플로우

```
1. 변수 변경 감지 (자동) 또는 사용자 수동 트리거
      ↓
2. DAG 재계산 → 영향받는 노드 하이라이트
      ↓
3. High-risk 교차 존재 시 → 경고 배너 표시 (role="alert", aria-live="assertive")
      ↓
4. 개발자: [체크리스트 실행] 클릭 → 사전 검증 체크리스트 패널 슬라이드 인
      ↓
5. 전체 통과 → [배포 승인 가능] 상태 뱃지 표시
```

## 5. 디자인 시스템 연동 사양 (design-baseline.yaml v1.2 기준)

### 5-A. 순환참조방지 4규칙 UI 적용

| 규칙 ID | 규칙 내용 | UI 적용 방식 |
|---------|-----------|-------------|
| CIRC-001 | 변수 A → B → A 직접 순환 금지 | DAG에서 사이클 노드 🔴 표시 + 자동 차단 |
| CIRC-002 | 3단 이상 간접 순환 감지 | 경로 하이라이트 + 경고 토스트 |
| CIRC-003 | 동일 레이어 내 상호 참조 금지 | 레이어 경계선 시각 구분 (점선 vs 실선) |
| CIRC-004 | 외부 override 시 참조 체인 재계산 | override 발생 시 DAG 애니메이션 업데이트 |
