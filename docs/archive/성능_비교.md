## 2. 변경 내역

### Phase 2: requirements 중복 패키지 제거

**제거 패키지**:
- `flake8>=7.0` — ruff가 동일 기능 커버, CI에서 미사용
- `black>=23.0` — ruff format이 대체, CI에서 미사용

**영향 파일**:
- `requirements-dev.txt`
- `pyproject.toml` [dev] extras

**임포트 시간 영향**: 없음 (개발 전용 패키지)
**디스크 절감**: 약 2~3 MB (flake8 + black 합산)

### Phase 3: goal_tracker/__init__.py 지연 로딩 전환

**변경 방식**: PEP 562 `__getattr__` 지연 로딩 (Lazy Import)

**원인 분석**:
- `goal_tracker/__init__.py`가 10개 서브모듈을 패키지 로드 즉시 eager import
- `goal_tracker.state_machine`이 `from loguru import logger`를 최상위에서 import
- `loguru` 첫 로딩: ~67ms (C 확장 포함 복잡한 초기화)
- 외부 코드에서 `from goal_tracker import X` 패턴 사용 0건 확인 → eager re-export 불필요

**결과**:
```
before: import goal_tracker  →  110ms (loguru + 9개 서브모듈 즉시 로딩)
after:  import goal_tracker  →  0.5ms (빈 패키지 로딩만, 서브모듈은 실제 접근 시 지연 로딩)
```
