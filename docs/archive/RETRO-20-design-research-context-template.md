## 3. 변수 의존성 타임라인 뷰

> 리서치 결과가 "어떤 맥락"에서 생성되었는지 이력 형태로 시각화.

### 3-A. 타임라인 레이아웃

```
                    ┌──── 현재 조사 ────┐
날짜        모델 버전  infra 버전  조사 결과   교차 변경
──────────  ─────────  ──────────  ──────────  ──────────
2026-03-29  2.5-flash  v1.2        RETRO-20    🟢 없음
2026-03-27  2.5-flash  v1.1    ◀── 결과 차이?  🟡 infra만
2026-03-25  2.0-flash  v1.1        RETRO-14    🔴 모델+infra
2026-03-24  2.0-flash  v1.0        RETRO-08    🟢 없음
```

**🔴 빨간 행 (2026-03-25)**: 모델 버전 AND infra 버전이 동시에 달라진 구간 → 결과 차이의 원인 이분 불가 → 사후 조사 시 이 구간 집중 검토 필요

### 3-B. 교차 변경 감지 뱃지

| 상태 | 뱃지 텍스트 | 색상 | ARIA |
|------|------------|------|------|
| 변경 없음 | `🟢 안정` | `#16A34A` | `aria-label="변수 변경 없음"` |
| 1개 변경 | `🟡 단독 변경` | `#D97706` | `aria-label="변수 1개 변경됨: 원인 추적 가능"` |
| 2개+ 동시 변경 | `🔴 교차 위험` | `#DC2626` | `aria-label="다중 변수 동시 변경: 원인 이분 불가"` |

## 6. cross_variable_periods 시각화 (RETRO-20 ACTION 연계)

> `research_context_schema.yaml`의 `variables_context.cross_variable_periods` 구조를 시각화.

### 6-A. 기간별 교차 구간 표시

```
        [모델 변경] [infra 변경]    [동시 변경 구간]
──────┬──────┬──────┬──────┬──────┬──────────────────
 3/24  3/25   3/26   3/27   3/28   3/29
  │     │      │      │      │      │
  🟢   🔴교차  🟢     🟡     🟢     🟢
```

**범례**:
- 🔴 교차: 2개 이상 변수 동시 변경 → 해당 구간 조사 결과는 "원인 불명 구간"으로 태깅
- 🟡: 1개 변수만 변경 → 단독 원인 추적 가능
- 🟢: 변경 없음 → 가장 신뢰도 높은 구간
