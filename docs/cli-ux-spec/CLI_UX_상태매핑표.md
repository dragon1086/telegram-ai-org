# CLI UX 상태매핑표
> 작성일: 2026-04-01 | 버전: v1.0 | 담당: 디자인실
> 대상 스크립트: `scripts/setup.sh` / `install.sh`
> 목적: 초보자가 아무것도 모르는 상태에서 실행해도 무슨 일이 일어나는지 이해할 수 있도록 각 단계별 상태를 정의

---

## 1. 전체 설치 플로우 단계 열거

```
[시작]
  ↓
PRE-0. 스크립트 진입 / OS 감지
  ↓
PRE-1. Node.js / npm 확인 및 자동 설치
  ↓
STEP 1/5. AI 엔진 자동 감지 + 설치 (claude-code / codex / gemini-cli)
  ↓
STEP 2/5. Python 버전 확인 (3.11+ 요구)
  ↓
STEP 3/5. Python 의존성 설치 (venv + pip/uv)
  ↓
STEP 4/5. 환경 변수 파일 설정 (.env)
  ↓
STEP 5/5. 헬스체크 (패키지 import + 엔진 바이너리)
  ↓
POST-1. 실행 파일 권한 설정 (chmod)
  ↓
POST-2. 에이전트 설치 (install_agents.sh)
  ↓
[완료] 엔진 요약표 + 다음 단계 안내
```

## 2. 단계별 상태 매핑표

| 단계 ID | 단계명 | 성공(✅) | 진행중(⏳) | 실패(❌) | 스킵(⏭️) | 경고(⚠️) |
|---------|--------|----------|-----------|---------|---------|---------|
| PRE-0 | 스크립트 시작 / OS 감지 | macOS/Linux 감지 | - | 미지원 OS | - | - |
| PRE-1 | Node.js/npm 확인 | v18+ 감지 | 설치 진행 | 설치 실패 | 이미 설치됨 | v18 미만 감지 |
| STEP-1a | claude-code 감지/설치 | 설치 확인 | npm 설치 중 | 설치 실패 | 사용자 거부 / --yes 전용 | - |
| STEP-1b | codex 감지/설치 | 설치 확인 | npm 설치 중 | 설치 실패 | 사용자 거부 | - |
| STEP-1c | gemini-cli 감지/설치 | 설치 확인 | brew/npm 설치 중 | 설치 실패 | 사용자 거부 | - |
| STEP-2 | Python 버전 확인 | 3.11+ 감지 | - | 3.10 이하 감지 | - | - |
| STEP-3a | 가상환경(venv) 생성 | 생성 완료 | 생성 중 | 생성 실패 | --no-venv 플래그 | - |
| STEP-3b | pip 의존성 설치 | 설치 완료 | 설치 중 | 설치 실패 | - | - |
| STEP-4 | .env 파일 생성 | 생성/갱신 완료 | - | 템플릿 없음 | 이미 존재 (덮어쓰기 거부) | 필수 키 미입력 |
| STEP-5 | 헬스체크 | 전 항목 통과 | 검사 중 | 임포트/바이너리 오류 | --skip-verify | 일부 항목 경고 |
| POST-1 | 실행 파일 권한 | chmod 완료 | - | 권한 오류 | - | - |
| POST-2 | 에이전트 설치 | 설치 완료 | 복사 중 | 경로 없음 | agents 디렉토리 없음 | - |
| FINAL | 설치 완료 + 엔진 요약 | 전체 완료 | - | 중단 종료 | - | 일부 엔진 미설치 |

## 3. 상태 정의 기준

| 상태 | 정의 | 사용자 기대 행동 |
|------|------|----------------|
| **성공** | 단계가 정상적으로 완료됨 | 다음 단계로 자동 진행 |
| **진행중** | 시간이 걸리는 작업이 실행 중 | 기다리면 됨 (사용자 개입 불필요) |
| **실패** | 오류 발생으로 단계 완료 불가 | 오류 메시지 + 해결 방법 확인 후 재시도 |
| **스킵** | 이미 완료됐거나 사용자가 건너뜀 | 자동으로 다음 단계 진행 |
| **경고** | 완료됐지만 주의 필요한 상황 | 메시지 읽고 계속 여부 판단 |

---

## 4. 3엔진 매핑 — 최소 1개 이상 필수

| 엔진 | 설치 방법 (우선순위) | 실패 시 대안 |
|------|---------------------|------------|
| claude-code | npm install -g @anthropic-ai/claude-code | brew install claude |
| codex | npm install -g @openai/codex | npm 필수, 대안 없음 |
| gemini-cli | brew install gemini-cli | npm install -g @google/gemini-cli |

> **핵심 의존성**: claude-code, codex는 npm 필수. gemini-cli는 brew 우선.
> → Node.js/npm 설치(PRE-1)가 STEP-1 전제 조건.

---

## 5. 엔진 0개 설치 시 중단 정책

- 3엔진 모두 미설치이고 자동 설치도 실패한 경우 → `exit 1` (설치 중단)
- 1개 이상 설치 성공 시 → 경고 후 계속 진행
- 스킵(사용자 거부)이 전부인 경우 → 안내 메시지 출력 후 종료
