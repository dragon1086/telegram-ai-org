## 2. PRE-1 — Node.js / npm 확인 및 자동 설치

> Node.js는 AI 엔진 설치에 꼭 필요한 프로그램입니다.

### 진행중 메시지

| 상황 | 문구 |
|------|------|
| 감지 시작 | `⏳ Node.js / npm 확인 중...` |
| macOS brew 설치 중 | `⏳ Node.js 설치 중... (Homebrew 사용, 1~2분 소요)` |
| Ubuntu NodeSource 설치 중 | `⏳ Node.js 18 설치 중... (NodeSource 사용, 1~2분 소요)` |

### 성공 메시지

| 상황 | 문구 |
|------|------|
| v18+ 이미 설치 | `✅ Node.js v20.x / npm 10.x 이미 설치됨` |
| 자동 설치 완료 | `✅ Node.js v18.x / npm 10.x 설치 완료` |

### 경고 메시지

| 상황 | 문구 |
|------|------|
| v18 미만 감지 | `⚠️  Node.js v14.x 감지됨 — 18 이상 필요, 업그레이드 시도 중` |

### 실패 메시지

| 상황 | 문구 | 힌트 |
|------|------|------|
| brew 없음 (macOS) | `❌ Node.js 설치 실패 — Homebrew가 없습니다` | `💡 https://brew.sh 에서 Homebrew를 먼저 설치 후 재시도하세요` |
| apt 설치 실패 (Linux) | `❌ Node.js 설치 실패 — 관리자 권한이 필요합니다` | `💡 sudo 권한으로 재시도: sudo bash install.sh` |
| 일반 실패 | `❌ Node.js 자동 설치 실패` | `💡 수동 설치: https://nodejs.org → 설치 후 다시 실행하세요` |

### 스킵 메시지

| 상황 | 문구 |
|------|------|
| 사용자 거부 | `⏭️  Node.js 설치 건너뜀 — AI 엔진 npm 설치가 제한될 수 있음` |

### 대화형 프롬프트 문구

```
  ❓ Node.js가 없습니다. 지금 자동으로 설치할까요? [Y/n]:
```
