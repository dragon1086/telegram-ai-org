# CLI UX 셀프 검수 체크리스트
> 작성일: 2026-04-01 | 버전: v1.0 | 담당: 디자인실
> 목적: 구현 완료 후 개발실이 초보자 관점에서 스스로 검수하는 기준

---

## 검수 방법

1. Ubuntu 22.04 클린 VM (또는 Docker 컨테이너) 에서 `bash install.sh` 실행
2. 아래 체크리스트 항목을 순서대로 확인
3. ❌ 항목이 있으면 수정 후 재검수

---

## A. 초보자 언어 기준 (UX 문구)

| # | 체크 항목 | 기준 | 결과 |
|---|----------|------|------|
| A-1 | 모든 오류 메시지에 해결 힌트(💡)가 포함되어 있는가? | err() 바로 다음 줄에 hint() 존재 | ☐ |
| A-2 | 기술 용어(npm, venv, ANSI 등)를 사용할 때 괄호 설명을 붙였는가? | 예: `npm (패키지 설치 도구)` — 단 명령어 자체는 그대로 | ☐ |
| A-3 | "설치 중..." 메시지에 예상 소요 시간이 명시되어 있는가? | 1분 이상 걸리는 작업 모두 해당 | ☐ |
| A-4 | 스킵 메시지에 건너뛴 이유와 영향을 명시했는가? | "건너뜀 — [이유], [영향]" 형태 | ☐ |
| A-5 | 설치 완료 후 "지금 당장 뭘 해야 하는지" 1줄로 알 수 있는가? | Next-Step 첫 줄이 `bash scripts/start_all.sh` | ☐ |
| A-6 | 모든 문구가 1줄 80자 이내인가? (힌트·명령어 포함) | 최대 2줄 허용, 그 이상은 분리 | ☐ |
| A-7 | "오류 코드" 또는 "스택 트레이스"만 출력하고 설명 없이 끝나는 경우가 없는가? | 항상 사람 말로 된 오류 설명 동반 | ☐ |

## B. 아이콘·컬러 시스템

| # | 체크 항목 | 기준 | 결과 |
|---|----------|------|------|
| B-1 | 모든 상태 메시지에 아이콘이 붙어 있는가? | ok/warn/err/info/skip/hint/step 함수 사용 | ☐ |
| B-2 | 색상만으로 상태를 구분하는 경우가 없는가? | 아이콘 없이 컬러만 사용 금지 | ☐ |
| B-3 | 모든 ANSI 컬러 코드 끝에 `\033[0m` (RESET)이 붙어 있는가? | 다음 줄 색상 오염 방지 | ☐ |
| B-4 | NO_COLOR=1 설정 시 컬러 없이 아이콘+텍스트만 출력되는가? | 로그 파일에 ANSI 코드 오염 없음 | ☐ |
| B-5 | 단계 헤더(▶ Step X/5:)가 내용과 시각적으로 구분되는가? | BLUE+BOLD 컬러 + 빈 줄 구분 | ☐ |
| B-6 | 완료 배너(🎉)가 눈에 띄게 강조되어 있는가? | GREEN+BOLD, 박스 형태 | ☐ |

## C. 설치 플로우 완전성

| # | 체크 항목 | 기준 | 결과 |
|---|----------|------|------|
| C-1 | Node.js 미설치 상태에서 자동 설치 시도 메시지가 출력되는가? | PRE-1 단계 명확히 표시 | ☐ |
| C-2 | Node.js 설치 실패 시 수동 설치 URL이 출력되는가? | `https://nodejs.org` 또는 brew/apt 명령어 | ☐ |
| C-3 | 3엔진 각각의 설치 결과(성공/스킵/실패)가 개별적으로 표시되는가? | 뭉뚱그려서 "엔진 설치 완료" 금지 | ☐ |
| C-4 | 3엔진 전부 실패 시 exit 1로 중단되고 안내 메시지가 출력되는가? | 빈 봇 실행 방지 | ☐ |
| C-5 | 엔진 요약표가 설치 완료 후 항상 출력되는가? | 3엔진 상태 한눈에 확인 | ☐ |
| C-6 | --yes 모드에서 모든 단계가 무인(non-interactive)으로 진행되는가? | CI 환경 대응 | ☐ |
| C-7 | Python 3.10 이하 감지 시 오류와 함께 설치 방법이 안내되는가? | OS별 분기 (brew/apt) | ☐ |
