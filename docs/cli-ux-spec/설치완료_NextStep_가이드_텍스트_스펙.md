# 설치 완료 Next-Step 가이드 텍스트 스펙
> 작성일: 2026-04-01 | 버전: v1.0 | 담당: 디자인실
> 목적: 설치가 끝난 초보자가 "이제 뭘 해야 하지?"에 즉시 답하는 가이드

---

## 설계 원칙

1. **가장 먼저 할 일 1개만 강조** — 선택지가 많으면 아무것도 안 함
2. **명령어는 그대로 복사해서 실행 가능하게** — 설명 없이 바로 붙여넣기 가능
3. **조건 분기 최소화** — "토큰 설정했으면 A, 아니면 B" 형태 대신 순서 제시
4. **1줄 1행동** — 각 항목은 사용자가 취해야 할 행동 1개

---

## 1. 시나리오별 Next-Step 가이드

### 시나리오 A: 전체 성공 (모든 엔진 + 토큰 설정 완료)

```
🎉 설치 완료! 이제 봇을 시작할 수 있습니다.

┌─ 다음 단계 ─────────────────────────────────────────────┐
│                                                          │
│  1. 봇 시작                                              │
│     bash scripts/start_all.sh                           │
│                                                          │
│  2. 텔레그램에서 봇에게 메시지를 보내 보세요              │
│     그룹 채팅방에서 @봇이름 에게 말 걸기                  │
│                                                          │
│  3. 상태 확인                                            │
│     bash scripts/health_check.py                        │
│                                                          │
└──────────────────────────────────────────────────────────┘

📖 전체 사용 가이드: cat docs/QUICKSTART.md
```

### 시나리오 B: 성공 (토큰 미설정)

```
🎉 설치 완료! 봇 토큰 설정이 남아 있습니다.

┌─ 다음 단계 ─────────────────────────────────────────────┐
│                                                          │
│  1. 텔레그램 봇 토큰 설정 (필수)                         │
│     .env 파일을 열어서 아래 값을 입력하세요:              │
│                                                          │
│     PM_BOT_TOKEN=여기에_봇_토큰_입력                     │
│     TELEGRAM_GROUP_CHAT_ID=여기에_그룹_ID_입력            │
│                                                          │
│     .env 파일 위치: ./  (현재 폴더)                      │
│                                                          │
│  2. 토큰 발급 방법 (모르는 경우)                         │
│     텔레그램에서 @BotFather 에게 /newbot 전송             │
│     → 안내에 따라 봇 생성 → 토큰 복사                    │
│                                                          │
│  3. 설정 완료 후 봇 시작                                  │
│     bash scripts/start_all.sh                           │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 3. Next-Step 가이드 항목별 상세 스펙

| 항목 | 텍스트 | 길이 | 조건 |
|------|--------|------|------|
| 봇 시작 명령어 | `bash scripts/start_all.sh` | 1줄 | 항상 |
| 토큰 설정 안내 | `.env 파일에서 PM_BOT_TOKEN= 값을 입력하세요` | 1줄 | 토큰 미설정 시 |
| BotFather 안내 | `@BotFather 에게 /newbot 전송 → 토큰 복사` | 1줄 | 토큰 발급 방법 모를 때 |
| 헬스체크 명령어 | `bash scripts/health_check.py` | 1줄 | 상태 확인 필요 시 |
| 문서 링크 | `cat docs/QUICKSTART.md` | 1줄 | 항상 |
| 에이전트 목록 | `ls ~/.claude/agents/` | 1줄 | 에이전트 확인 원할 때 |
| 설정 파일 위치 | `.env  (현재 폴더에 있음)` | 1줄 | 설정 파일 찾을 때 |
| GitHub 이슈 | `https://github.com/[owner]/[repo]/issues` | 1줄 | 오류 발생 시 |
