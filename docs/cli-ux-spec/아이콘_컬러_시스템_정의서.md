# 아이콘·컬러 시스템 정의서
> 작성일: 2026-04-01 | 버전: v1.0 | 담당: 디자인실
> 기준: WCAG 2.1 대비 기준 + 초보자 가독성 최우선
> 적용 대상: `scripts/setup.sh` CLI 출력 전체

## 1. 아이콘 시스템

### 1.1 기본 5종 아이콘 확정

| 아이콘 | 이름 | 의미 | 사용 상황 |
|--------|------|------|----------|
| ✅ | SUCCESS | 단계 완료, 정상 동작 | ok() 함수 — 성공 메시지 |
| ⏳ | PROGRESS | 작업 진행 중 | info() 함수 — 설치/다운로드 중 |
| ❌ | ERROR | 오류 발생, 단계 실패 | err() 함수 — 치명적 오류 |
| ⚠️ | WARNING | 주의 필요, 비치명적 문제 | warn() 함수 — 경고 상황 |
| ⏭️ | SKIP | 단계 건너뜀 | skip() 함수 — 스킵 안내 |

### 1.2 보조 아이콘 (추가 필요 검토 결과)

| 아이콘 | 이름 | 의미 | 추가 사유 |
|--------|------|------|----------|
| ▶ | STEP | 단계 시작 | step() 함수 — 단계 헤더 강조 (기존 사용 중) |
| ℹ️ | INFO | 중립 정보 | info() 함수 — 진행 상황 알림 (기존 사용 중) |
| ❓ | QUESTION | 사용자 입력 요청 | 대화형 프롬프트 앞 (Y/n 선택 등) |
| 🎉 | COMPLETE | 전체 설치 완료 | FINAL 단계 — 초보자에게 성공감 전달 |
| 📋 | GUIDE | 다음 단계 안내 | Next-Step 가이드 블록 헤더 |
| 💡 | HINT | 해결 힌트 | 실패 메시지 하단 해결 방법 |

> **결론**: ✅/⏳/❌ 3종 + ⚠️/⏭️ 2종 = **5종 기본**, 보조 6종 추가로 총 **11종 아이콘 체계** 사용.
> 아이콘 없이 색상만 쓰면 색맹 사용자가 상태를 구분 못함 → 아이콘+컬러 병용 필수(WCAG SC 1.4.1).

## 2. 컬러 시스템 (ANSI 코드 기반)

### 2.1 터미널 컬러 팔레트

| 색상 이름 | ANSI 코드 | Hex 참조값 | 용도 | 상태 연결 |
|----------|-----------|-----------|------|----------|
| **GREEN** | `\033[0;32m` | #22C55E | 성공, 완료 | ✅ SUCCESS |
| **YELLOW** | `\033[1;33m` | #EAB308 | 경고, 주의 | ⚠️ WARNING |
| **RED** | `\033[0;31m` | #EF4444 | 오류, 실패 | ❌ ERROR |
| **CYAN** | `\033[0;36m` | #06B6D4 | 정보, 진행중 | ⏳ PROGRESS / ℹ️ INFO |
| **BLUE (BOLD)** | `\033[1m\033[0;34m` | #3B82F6 | 단계 헤더 | ▶ STEP |
| **GRAY** | `\033[0;90m` | #6B7280 | 스킵, 비활성 | ⏭️ SKIP |
| **BOLD WHITE** | `\033[1m` | #FFFFFF | 강조 텍스트 | 완료 배너 |
| **RESET** | `\033[0m` | - | 색상 초기화 | 모든 줄 끝 |

### 2.2 상태별 컬러+아이콘 조합 매핑

| 상태 | 아이콘 | 컬러 | ANSI 적용 예시 |
|------|--------|------|---------------|
| 성공 | ✅ | GREEN | `\033[0;32m✅ 메시지\033[0m` |
| 진행중 | ⏳ | CYAN | `\033[0;36mⅰ️  메시지\033[0m` |
| 실패 | ❌ | RED | `\033[0;31m❌ 메시지\033[0m` |
| 경고 | ⚠️ | YELLOW | `\033[1;33m⚠️  메시지\033[0m` |
| 스킵 | ⏭️ | GRAY | `\033[0;90m⏭️  메시지\033[0m` |
| 단계 헤더 | ▶ | BLUE+BOLD | `\033[1m\033[0;34m▶ Step X/5: ...\033[0m` |
| 완료 배너 | 🎉 | GREEN+BOLD | `\033[1m\033[0;32m🎉 ...\033[0m` |
| 힌트 | 💡 | CYAN | `\033[0;36m💡 ...\033[0m` |

## 3. WCAG 접근성 검토 (severity 3단계)

### 3.1 WCAG SC 1.4.1 — 색상만으로 정보 전달 금지

> **요건**: 색상 외에 아이콘 또는 텍스트 레이블로 상태를 구분해야 함.

| 위반 패턴 | 해결 방법 | 적용 여부 |
|----------|----------|---------|
| 빨간 텍스트만으로 오류 표시 | ❌ 아이콘 + RED 컬러 병용 | ✅ 준수 |
| 초록 텍스트만으로 성공 표시 | ✅ 아이콘 + GREEN 컬러 병용 | ✅ 준수 |
| 노란 텍스트만으로 경고 표시 | ⚠️ 아이콘 + YELLOW 컬러 병용 | ✅ 준수 |

### 3.2 Severity 3단계 컬러 대비 기준

| Severity | 상태 | 컬러 | 배경 기준 대비비 | 접근성 등급 |
|----------|------|------|----------------|-----------|
| **HIGH** (즉각 주의) | ERROR (❌) | RED `#EF4444` | 검은 배경: 4.6:1 ✅ | WCAG AA |
| **MEDIUM** (주의 필요) | WARNING (⚠️) | YELLOW `#EAB308` | 검은 배경: 8.3:1 ✅ | WCAG AAA |
| **LOW** (참고) | INFO (ℹ️) | CYAN `#06B6D4` | 검은 배경: 5.8:1 ✅ | WCAG AA |
| **OK** (정상) | SUCCESS (✅) | GREEN `#22C55E` | 검은 배경: 5.0:1 ✅ | WCAG AA |
| **INACTIVE** (비활성) | SKIP (⏭️) | GRAY `#6B7280` | 검은 배경: 4.5:1 ✅ | WCAG AA |

> **참고**: 터미널 기본 배경은 검은색(#000000) 또는 매우 어두운 색 기준.
> 밝은 테마 터미널 사용자는 GRAY가 가독성 저하될 수 있음 → GRAY 사용 최소화, SKIP 상태는 텍스트 레이블 병행.

### 3.3 색맹 대응

| 색맹 유형 | 영향 컬러 조합 | 대응 방법 |
|----------|-------------|---------|
| 적록색맹 (가장 흔함) | RED ↔ GREEN 구분 불가 | ❌/✅ 아이콘으로 구분 (필수) |
| 황청색맹 | YELLOW ↔ CYAN 구분 불가 | ⚠️/ℹ️ 아이콘으로 구분 |
| 단색형 색맹 | 모든 색 구분 불가 | 아이콘 + 텍스트 레이블 필수 |

## 4. 컬러 출력 no-color 지원 정책

```bash
# NO_COLOR 환경변수 또는 파이프 출력 시 컬러 비활성화 권장
if [[ -n "${NO_COLOR:-}" ]] || [[ ! -t 1 ]]; then
    RED='' GREEN='' YELLOW='' BLUE='' CYAN='' BOLD='' RESET=''
fi
```

> 이 정책을 적용하면 `bash setup.sh 2>&1 | tee install.log` 형태로 로그 파일 저장 시 ANSI 코드 오염 방지.
