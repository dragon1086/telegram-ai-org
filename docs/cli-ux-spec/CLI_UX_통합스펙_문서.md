# CLI UX 통합 스펙 문서
> 작성일: 2026-04-01 | 버전: v1.0 | 담당: 디자인실
> 목적: 개발실이 바로 구현에 활용할 수 있는 완전한 CLI UX 레퍼런스
> 적용 대상: `scripts/setup.sh` npm/엔진 자동 설치 UX 전면 개선

---

## 결론 요약

**초보자가 `bash install.sh` 한 번으로 전체 설치를 완료할 수 있도록**, 각 단계마다 무슨 일이 일어나는지 명확히 알려주는 CLI UX 시스템을 정의한다.
핵심은 3가지: **아이콘+컬러 병용**(색맹 대응), **1줄 초보자 언어 문구**, **설치 완료 후 즉시 실행 가능한 Next-Step**.

## ① 상태별 아이콘 + 컬러 + 문구 조합 대조표

| 상태 | 아이콘 | ANSI 컬러 | 함수 | 문구 패턴 |
|------|--------|-----------|------|----------|
| **성공** | ✅ | `\033[0;32m` GREEN | `ok()` | `✅ [완료된 것] 완료` |
| **진행중** | ⏳ | `\033[0;36m` CYAN | `info()` | `⏳ [하고 있는 것] 중... (X분 소요)` |
| **실패** | ❌ | `\033[0;31m` RED | `err()` | `❌ [실패한 것] 실패 — [이유]` |
| **경고** | ⚠️ | `\033[1;33m` YELLOW | `warn()` | `⚠️  [주의 사항] — [영향]` |
| **스킵** | ⏭️ | `\033[0;90m` GRAY | `skip()` | `⏭️  [건너뛴 것] 건너뜀 — [이유]` |
| **힌트** | 💡 | `\033[0;36m` CYAN | `hint()` | `💡 [해결 방법]: [명령어 또는 URL]` |
| **단계** | ▶ | `\033[1m\033[0;34m` BLUE+BOLD | `step()` | `▶ Step X/5: [단계명]` |
| **완료** | 🎉 | `\033[1m\033[0;32m` GREEN+BOLD | `done_banner()` | `🎉 설치 완료! ...` |

### 신규 추가 필요 함수 (현재 setup.sh 미구현)

```bash
skip() { echo -e "\033[0;90m⏭️  $*\033[0m"; }
hint() { echo -e "\033[0;36m💡 $*\033[0m"; }
done_banner() { echo -e "\033[1m\033[0;32m🎉 $*\033[0m"; }
```

## ③ Next-Step 가이드 전체 시나리오

| 시나리오 | 조건 | 첫 번째 Next-Step |
|----------|------|------------------|
| **A. 완전 성공** | 엔진 1+ 설치 + 토큰 설정 | `bash scripts/start_all.sh` |
| **B. 토큰 미설정** | 엔진 설치됨 + .env 비어있음 | `.env 파일에서 PM_BOT_TOKEN= 설정` |
| **C. 일부 엔진 없음** | 엔진 1+ 설치 + 나머지 스킵 | `bash scripts/start_all.sh` (가능) + 미설치 엔진 수동 설치 안내 |
| **D. 전체 실패** | 엔진 0개 설치 | 수동 설치 명령어 제공 |

## ④ 접근성 주의사항

### 반드시 지켜야 할 규칙

| 규칙 | 이유 | 구현 방법 |
|------|------|---------|
| 색상만으로 상태 구분 금지 | WCAG SC 1.4.1 — 적록색맹 사용자 대응 | 아이콘+컬러 항상 병용 |
| 모든 ANSI 코드 끝에 `\033[0m` | 다음 줄 색상 오염 방지 | RESET 상수 사용 |
| NO_COLOR 환경변수 존중 | 로그 파일·파이프 출력 대응 | 스크립트 상단 컬러 비활성화 블록 |
| 긴 설치 작업엔 소요 시간 명시 | 초보자 불안감 해소 | `(1~2분 소요)` 병기 |
| 실패 메시지엔 항상 힌트 포함 | 막막함 방지 | `💡 수동: ...` 바로 다음 줄 |

### ANSI 컬러 코드 구현 블록 (setup.sh 상단 추가)

```bash
# ── 컬러 비활성화 (NO_COLOR 또는 파이프 출력 시) ──────────────────────────────
if [[ -n "${NO_COLOR:-}" ]] || [[ ! -t 1 ]]; then
    RED='' GREEN='' YELLOW='' BLUE='' CYAN='' BOLD='' RESET=''
fi

# ── 신규 함수 (기존 ok/warn/err/info/step 외 추가) ────────────────────────────
skip()      { echo -e "${GRAY}⏭️  $*${RESET}"; }
hint()      { echo -e "${CYAN}💡 $*${RESET}"; }
done_banner(){ echo -e "\n${BOLD}${GREEN}🎉 $*${RESET}\n"; }
```

### 색맹 대응 체크

| 색맹 유형 | 위험 조합 | 대응 여부 |
|----------|----------|---------|
| 적록색맹 | RED(❌) vs GREEN(✅) | ✅ 아이콘으로 구분 |
| 황청색맹 | YELLOW(⚠️) vs CYAN(⏳) | ✅ 아이콘으로 구분 |
| 단색형 | 전체 | ✅ 아이콘+텍스트 레이블 |
