## 7. 핵심 설계 결정사항 요약

1. **진행률 바 20자 고정 너비** — 텔레그램 메시지 최대 너비 40char 내 균형 유지.
   5% = 1 블록 단위로 업데이트 빈도 최소화 (API 레이트리밋 대응).

2. **캐릭터 이모지 + 상태 배지 2-레이어** — 봇 신원(💻🎨🔬 등)과 상태(🟢🟡🔴)를
   독립된 이모지로 분리하여 조합 가능. 화면이 좁아도 즉시 인식 가능.

3. **단일 행 주요 CTA 원칙** — 원클릭 셋팅 등 주요 액션은 반드시 단독 행 배치.
   보조 버튼은 최대 3열로 묶어 하위 행에 배치.

4. **메시지 편집 전략** — 새 메시지 대신 동일 message_id 편집으로 피드 오염 방지.
   진행률 10% 변화 단위로만 편집하여 API 호출 최소화.

5. **박스 스타일 카드 (╔══╗)** — 텔레그램 모노스페이스 폰트 환경에서 시각적 계층을
   명확히 구분. 헤더/본문/푸터 3단 구조를 고정 패턴으로 통일.
