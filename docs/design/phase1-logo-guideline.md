# AI·ORG 프로젝트 로고 가이드라인 v1.0

> Phase 1 로고 컨셉 최종 2종 사용 가이드라인 (2026-03-31)

## 1. 로고 컨셉 요약

### 컨셉 A — "Circuit Bot" (주력 로고)

**심볼 묘사**:
- 형태: 원형(48px 기준) 안에 봇키(Botki) 마스코트 얼굴 정면
- 원형 테두리: 2px 선, 회로 패턴(점선 노드) 삽입
- 내부: 봇키 얼굴 — 반달 눈, 고양이 귀, 안테나
- 배경: 심볼 내부 다크 #0A0E1A

**워드마크**:
- 텍스트: "AI·ORG"
- 폰트: Bangers (Google Fonts), 자간 +4px
- 중간 점(·): 로고 심볼의 안테나 색상(#00D4FF)으로 강조
- 서브텍스트: "Multi-Bot Platform" (Roboto Light 12px, #888888)

**배리에이션 A-1 — 다크 모드 (기본)**:
```
배경: #0A0E1A
심볼 테두리: #00D4FF
봇키 몸통: #4A90E2
워드마크: #FFFFFF
서브텍스트: #00D4FF
```

**배리에이션 A-2 — 라이트 모드**:
```
배경: #FFFFFF
심볼 테두리: #2D6A4F
봇키 몸통: #4A90E2
워드마크: #0A0E1A
서브텍스트: #2D6A4F
```

---

### 컨셉 B — "Minimal Mark" (심플 버전)

**심볼 묘사**:
- 형태: 정방형 라운드 아이콘 (48×48px, 반경 12px)
- 내부: 미니멀한 회로 패턴 + "A" 글자 변형 (A 위에 안테나 연장)
- 색상: #00D4FF 단색

**워드마크**:
- 텍스트: "aiorg"
- 폰트: Inter Bold, 소문자
- 색상: 다크 모드 #FFFFFF / 라이트 모드 #0A0E1A

**사용 맥락**: 파비콘, 작은 배지, 텍스트 중심 문서 헤더

## 4. 여백 규정 (Clear Space)

로고 주변 최소 여백 = 로고 심볼 높이의 **25%**

예시:
- 32px 로고 → 최소 8px 사방 여백
- 80px 로고 → 최소 20px 사방 여백

```
         ← 25% →
    ┌────────────────┐
    │                │
↑   │   [AI·ORG]    │   ↑
25% │                │  25%
↓   │                │   ↓
    └────────────────┘
         ← 25% →
```

## 5. 금지 사용 사례

### 절대 금지
1. **색상 변경**: 브랜드 팔레트 외 임의 색상 적용
2. **비율 왜곡**: 가로/세로 비율 변경 (stretch, squish)
3. **회전**: 어떠한 각도로도 회전 금지
4. **그림자 추가**: drop-shadow 효과 임의 추가
5. **저해상도 확대**: 권장 최소 크기 이하 무리한 확대
6. **배경 혼합**: 대비율 3:1 미만 배경에 사용 (WCAG 위반)
7. **텍스트 겹침**: 워드마크 위에 다른 텍스트 오버레이

### 주의 사항
1. 컬러 로고를 단색 배경 외에 이미지 위에 사용 시 → 배경 레이어(반투명) 필수
2. 소셜미디어 프로필 사진 사용 시 → 심볼만, 워드마크 제외
