#### 2.1.5 티켓 패널 인터랙션 명세

| 이벤트 | 트리거 | 동작 | 전환 시간 |
|--------|--------|------|----------|
| 호버 | mouseenter | 카드 확장 + 그림자 강화 + Y -2px 이동 | 0.2s ease |
| 호버 종료 | mouseleave | 카드 원상복구 | 0.2s ease |
| 클릭 | click | 우측에서 상세 드로어 슬라이드인 | 0.3s ease-out |
| 드로어 닫기 | overlay click / ESC | 드로어 슬라이드아웃 | 0.25s ease-in |
| SSE 이벤트 | 신규 태스크 수신 | 카드 상단 슬라이드인 + 카운터 증가 | 0.4s spring |
| SSE 이벤트 | 상태 변경 | 뱃지 컬러 전환 + 카운터 갱신 | 0.3s ease |
| 자동 갱신 | 30초 타이머 | 카운터 빠른 플립 애니메이션 | 0.15s |

### 3.2 감정 상태 명세 (5종)

#### 상태 1 — IDLE (기본형)

```
     🌀← 안테나 (파란 불, 천천히 깜빡)
    (◕ᴗ◕)← 눈: 반달 형태, 입: 작은 웃음
     [🤖]
    /    \← 양손 모아 앞에 놓기
```

| 속성 | 값 |
|------|-----|
| 트리거 조건 | 정상 운영, 특별 이벤트 없음 |
| 눈 표현 | 반달 (◕) — 휴식 중 |
| 안테나 | 파란 불, 3초 주기 천천히 점멸 |
| 포즈 | 양손 모아 대기 자세 |
| 기본 애니메이션 | 상하 부유 (float 4s) |
| 말풍선 | 없음 (호버 시 "모든 시스템 정상" 툴팁) |
| 전환 조건 | pending > 3개 → WORKING / 신규 SSE → ALERT |

#### 상태 2 — WORKING (작업 중)

```
    🌀🌀← 안테나 빙글빙글 회전
    (>ᴗ<)← 눈: 집중 눈썹, 조금 좁아진 눈
     [🤖]
    /🔧 \← 오른손에 렌치, 왼손 주먹
```

| 속성 | 값 |
|------|-----|
| 트리거 조건 | `in_progress` 태스크 3개 이상 |
| 눈 표현 | 집중된 눈썹 + 좁아진 눈 (>ᴗ<) |
| 안테나 | 빠른 회전 (1초 1바퀴) |
| 포즈 | 한 손에 렌치, 작업 몸짓 |
| 기본 애니메이션 | 미세한 좌우 흔들림 (work-bob 2s) |
| 말풍선 | `"{n}개 작업 진행 중..."` |
| 전환 조건 | in_progress 감소 → IDLE / 신규 ALERT → ALERT |

```css
@keyframes work-bob {
  0%, 100% { transform: rotate(-3deg); }
  50% { transform: rotate(3deg); }
}
```

```
  ✗ 비승인 컬러 조합 사용 (배리에이션 A/B 외)
  ✗ 회전, 기울임, 왜곡
  ✗ 복잡한 배경 위에 단독 배치 (필요 시 배경 박스 추가)
  ✗ 워드마크 폰트 임의 변경
  ✗ 심볼 없이 워드마크만 사용 (단, 공간 제약 시 예외)
  ✗ 주색 외 컬러로 심볼 테두리 처리
```
