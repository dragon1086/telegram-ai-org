# Phase 1 — 사용자 분석

## 1-A. 페르소나 정의

### Persona A — DevOps / 시스템 운영자 "김서버"

| 항목 | 내용 |
|------|------|
| **나이/역할** | 28세, 스타트업 인프라 담당 |
| **AIMesh 사용 목적** | AI 봇 조직 전체 운영 상태 모니터링, 장애 조기 감지 |
| **접근 환경** | MacBook (메인) + iPhone 텔레그램 (이동 중) |
| **기술 수준** | 높음 — CLI 편안, 로그 직독 가능 |

**Pain Points**

- `setup.sh` 56KB 스크립트 → 무엇을 하는지 한눈에 안 보임
- 봇 무반응 시 **원인 불명** — 로그 탭 열어야 파악
- 브라우저 대시보드 첫 로드 느림 (여러 CSS/JS 번들 직렬 로드)
- 원격 접근(ngrok) 상태가 어디 있는지 매번 찾아야 함

**핵심 니즈**

- "지금 무슨 일이 벌어지고 있나" → **5초 내 파악**
- exit 143 / pre-flight 실패 → **UI에서 즉각 원인 표시**
- 봇 재기동 → **1번 클릭**으로 완료

### Persona B — AI 기획/PM "박기획"

| 항목 | 내용 |
|------|------|
| **나이/역할** | 32세, AI 프로덕트 PM |
| **AIMesh 사용 목적** | 태스크 진행 현황 확인, 부서별 완료율 파악 |
| **접근 환경** | 텔레그램 대화방 + 웹 대시보드 (보조) |
| **기술 수준** | 중간 — 터미널 비선호, GUI 선호 |

**Pain Points**

- 완료된 태스크 목록이 **텔레그램 채팅방에 묻혀** 찾기 어려움
- 각 AI 조직이 "지금 뭘 하는 중인지" 한눈에 안 보임
- 설정 변경 시 `.env` 직접 편집 → 비기술 사용자 장벽 높음

**핵심 니즈**

- 조직별 현황 → **캐릭터 카드** 형태로 직관적 파악
- 완료 태스크 → **스크롤 가능한 카드 목록** (최근 50건)
- 설정 → **원클릭 토글** 또는 **단계별 온보딩 위저드**

### Persona C — 오픈소스 신규 사용자 "이뉴비"

| 항목 | 내용 |
|------|------|
| **나이/역할** | 22세, 개인 개발자 |
| **AIMesh 사용 목적** | GitHub에서 발견, 내 프로젝트에 AI 조직 붙여보기 |
| **접근 환경** | Windows + WSL2 |
| **기술 수준** | 낮음-중간 — `git clone` / `pip install` 가능, 고급 설정 어려움 |

**Pain Points**

- README 길이가 너무 길어 **어디서 시작해야 할지 불명**
- `.env` 에 어떤 값을 채워야 하는지 **항목이 너무 많음**
- Docker vs Python 중 어떤 방법으로 실행해야 할지 모름
- 첫 실행 오류 시 **어디가 문제인지 피드백 없음**

**핵심 니즈**

- **원클릭 install** → `curl | bash` 또는 단일 `install.sh`
- 최소 필수 환경변수 3개만 입력 → 바로 실행
- 첫 실행 성공 → **캐릭터 환영 메시지** (동기부여)

## 1-C. UX 핵심 문제 진단 (3대 Pain 요약)

### 문제 ①: "원인 불명" — 피드백 채널 부재

```
현재: 봇 무반응 → 사용자가 로그 탭 수동 확인 → 원인 파악 (5~15분)
목표: 봇 무반응 → 대시보드 캐릭터 상태 변경 + 에러 배너 즉시 표시 (10초)
```

### 문제 ②: "무거운 진입점" — 설치 장벽

```
현재: setup.sh (56KB) → 50개 프롬프트 → 고급 사용자 전용
목표: install.sh (경량) → 3개 핵심 질문 → 누구나 5분 내 실행
```

### 문제 ③: "흩어진 정보" — 대시보드 미활용

```
현재: 정보가 텔레그램 채팅방 / 터미널 / 로그파일에 분산
목표: 단일 대시보드에서 티켓·완료작업·원격접근·캐릭터상태 통합 확인
```

## 2-F. 인터랙션 플로우 정의

```
사용자 행동                    UI 반응                        상태 변화
────────────                   ──────────                     ──────────
페이지 진입              →     SSE 연결 시작                  CONNECTING
                        →     캐릭터 패널 로드                IDLE 상태
                        →     티켓 카운터 초기값 표시

SSE 이벤트 수신          →     해당 패널만 플래시 업데이트
ticket_update           →     카운터 플래시 + 숫자 변경
task_complete           →     완료 목록 맨 위 삽입 + 🎉 파티클
character_update        →     캐릭터 표정/애니메이션 교체
remote_access_change    →     배지 색상 + latency 업데이트
error_event             →     에러 배너 슬라이드 인 + BLOCKED 상태

에러 배너 ×버튼 클릭    →     배너 슬라이드 아웃
봇 재기동 클릭          →     버튼 → RUNNING → 자동 READY 전환
```

# 경량화 처방 목록

## 제거/축소 대상 (현재 → 목표)

| 항목 | 현재 상태 | 처방 | 예상 효과 |
|------|-----------|------|-----------|
| `setup.sh` | 56KB, 50개 프롬프트 | `install.sh` 경량 진입점 추가 (기존 유지) | 신규 사용자 장벽 ↓ |
| CSS 폰트 로드 | Google Fonts 3개 직렬 로드 | `font-display: swap` + `preload` | 초기 렌더 차단 제거 |
| 대시보드 JS | 단일 번들 (미분리) | 패널별 lazy import | 초기 로드 크기 ↓ |
| SSE 재연결 | 없음 | exponential backoff + 최대 30s | 불필요한 폴링 제거 |
| `.env` 항목 수 | 30+ 항목 | 필수 3개 / 선택 나머지 | 온보딩 복잡도 ↓ |
| 봇 재기동 | 수동 터미널 명령 | 대시보드 버튼 1클릭 | 운영 동작 단순화 |
| 로그 파일 직접 조회 | 필요 | 에러 배너로 대체 | 문제 인지 시간 ↓ |

## 추가/강화 대상

| 항목 | 설명 | 우선순위 |
|------|------|----------|
| `install.sh` 원클릭 진입점 | 3단계 위저드 → `.env` 자동 생성 + 봇 실행 | ⭐⭐⭐ |
| 에러 배너 자동 표시 | pre-flight 실패 → UI 즉시 노출 | ⭐⭐⭐ |
| 캐릭터 상태 자동 갱신 | SSE 이벤트 → 캐릭터 표정/대사 실시간 교체 | ⭐⭐⭐ |
| `font-display: swap` | 폰트 로드 중 fallback 폰트 표시 | ⭐⭐ |
| 패널별 코드 분할 | 각 패널을 ES module로 lazy load | ⭐⭐ |

# WCAG 접근성 스펙

## WCAG 2.2 AA 기준 체크리스트

| 항목 | 기준 | 현재 구현 | 상태 |
|------|------|-----------|------|
| 색상 대비 — 일반 텍스트 | 4.5:1 이상 | `--comic-dark` on `--comic-bg` = 17.4:1 | ✅ |
| 색상 대비 — 굵은 텍스트 | 3.0:1 이상 | 모든 severity 컬러 검증 완료 | ✅ |
| 키보드 접근성 | Tab 순서, 포커스 링 | 패널 버튼 tabIndex 지원 | ✅ |
| 움직이는 콘텐츠 | prefers-reduced-motion | character 애니메이션에 미디어쿼리 필요 | ⚠️ 추가 필요 |
| 대체 텍스트 | 이미지/이모지 aria-label | 캐릭터 이모지 aria-label 미적용 | ⚠️ 추가 필요 |
| 에러 식별 | 텍스트로 오류 설명 | 에러 배너 텍스트 포함 | ✅ |
| 언어 명시 | `<html lang="ko">` | index.html 적용됨 | ✅ |

## 즉시 적용 필요 항목 (⚠️ 2건)
