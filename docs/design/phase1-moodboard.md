## 1. 대시보드 정보 구조 정의

### 1.1 핵심 원칙

AI 멀티봇 조직의 대시보드는 **"한 눈에 조직의 건강 상태를 읽는다"** 는 목표를 달성해야 한다. 사용자는 화면을 열자마자 5초 이내에 다음 세 가지 질문에 답할 수 있어야 한다.

1. 지금 몇 개의 태스크가 살아 있는가?
2. 오늘 얼마나 해냈는가?
3. 원격 접속은 가능한가?

이 세 질문이 각각 세 패널의 존재 이유다.

---

### 1.2 패널별 정보 우선순위

#### Priority 1 — 티켓 현황 패널 (최고 가시성)

> "지금 무슨 일이 일어나고 있는가?"

| 정보 요소 | 표현 방식 | 가시성 레벨 |
|-----------|-----------|-------------|
| 활성 태스크 총 수 | 대형 숫자 카운터 (48px Bold) | ★★★★★ |
| 상태별 분류: pending | 노랑 뱃지 + 카운트 | ★★★★☆ |
| 상태별 분류: in_progress | 파랑 뱃지 + 카운트 | ★★★★☆ |
| 상태별 분류: resolved | 초록 뱃지 + 카운트 | ★★★☆☆ |
| 긴급 알림 뱃지 | 빨강 점멸 도트 + 팝업 | ★★★★★ |
| 개별 태스크 카드 | 스크롤 가능한 카드 리스트 | ★★★☆☆ |
| 담당 봇 아바타 | 16px 인라인 아이콘 | ★★☆☆☆ |

**설계 근거**: 운영 중 가장 자주 확인하는 정보는 "지금 막혀 있는 것이 있는가"다. pending 카운트가 급격히 늘어나거나 in_progress가 장시간 변하지 않으면 이상 신호다. 최고 가시성을 부여하여 스캔 시간을 최소화한다.

**UX 패턴**: F-패턴 독서 흐름에 따라 최상단 좌측 배치. 숫자는 최소 48px 이상으로 원거리 모니터에서도 가독 가능.

---

#### Priority 2 — 완료 작업 패널 (성취감 강조)

> "오늘 우리는 무엇을 해냈는가?"

| 정보 요소 | 표현 방식 | 가시성 레벨 |
|-----------|-----------|-------------|
| 오늘 완료 태스크 수 | "TODAY: N" 헤더 카운터 | ★★★★☆ |
| 전체 완료율 진행바 | 애니메이션 프로그레스바 | ★★★★★ |
| 오늘 완료 타임라인 | 시간순 체크 리스트 | ★★★☆☆ |
| 조직별 기여도 | 색상 바 차트 + 수치 | ★★★★☆ |
| 달성 뱃지 | 목표 달성 시 팝업 애니메이션 | ★★★☆☆ |

**설계 근거**: 장시간 운영 환경에서 팀 모럴을 유지하는 핵심은 성취감의 시각화다. Netflix의 시청 기록 타임라인, Notion의 체크리스트 완료 애니메이션처럼 "완료했다는 느낌"을 증폭시키는 것이 중요하다.

**UX 패턴**: 진행바는 로드 시 0→N% 애니메이션 실행. 조직별 바는 컬러 코딩으로 기여 조직 즉시 식별.

---

#### Priority 3 — 원격 접근 패널 (접근성)

> "외부에서 접속할 수 있는가?"

| 정보 요소 | 표현 방식 | 가시성 레벨 |
|-----------|-----------|-------------|
| ngrok 상태 | ●LIVE/●OFFLINE 컬러 도트 | ★★★★★ |
| ngrok URL | 모노스페이스 + 복사 버튼 | ★★★★☆ |
| QR 코드 | 128×128px 영역 (모바일 대응) | ★★★☆☆ |
| 헬스체크 상태 | ✓/✗ 아이콘 + 마지막 체크 시각 | ★★★☆☆ |
| 응답 지연 (ping ms) | 숫자 + 색상 등급 (초록/노랑/빨강) | ★★★☆☆ |

**설계 근거**: 원격 접근 패널은 "있다는 안도감"을 주는 패널이다. 평상시엔 시선이 덜 가지만 문제 발생 시 즉시 눈에 띄어야 한다. 이를 위해 ●LIVE 도트는 항상 최상단에 위치하고, OFFLINE 상태에서는 빨강 배경으로 패널 전체가 경고를 발신한다.

## 2. 만화 캐릭터 컨셉 무드보드

### 2.1 AI 멀티봇 조직 아이덴티티

이 대시보드의 마스코트는 단순한 장식이 아니다. AI 멀티봇 조직의 **살아 있는 얼굴**이다. 여러 봇이 협력하여 작업을 수행하는 조직의 아이덴티티를 단 하나의 캐릭터로 표현해야 한다.

**핵심 키워드**: 협력, 기술, 친근함, 신뢰, 에너지

---

### 2.2 레퍼런스 수집 3축

#### 축 1 — 친근함 (Friendliness)

| 레퍼런스 | 특징 | 차용 포인트 |
|----------|------|-------------|
| **Slack Bolt 마스코트** | 번개 모양의 단순한 캐릭터, 팀 도구의 상징 | 단순화된 형태, 도구 친화적 이미지 |
| **LINE 프렌즈 (브라운/코니)** | 동글동글한 형태, 크고 맑은 눈, 과장된 표정 | 둥근 실루엣, 감정 표현의 과장성 |
| **Notion 마스코트** | 젠틀하고 지적인 느낌, 미니멀 얼굴 | 지적 친근함, 과하지 않은 표현 |
| **Duolingo Duo (올빼미)** | 밝고 에너지 넘치는 눈, 격려하는 자세 | 격려 포즈, 동적 제스처 |

**공통 형태 언어**:
- 머리:몸 비율 = 1:0.7 (두상 강조, 귀여움 극대화)
- 눈 크기 = 전체 얼굴의 30% (감정 전달 핵심)
- 모서리 곡률 = 최소 8px 이상 (날카로운 형태 금지)
- 팔다리 = 짧고 통통하게 (공격적이지 않은 인상)

---

#### 축 2 — 전문성 (Expertise)

| 레퍼런스 | 특징 | 차용 포인트 |
|----------|------|-------------|
| **MIT 미디어랩 비주얼** | 기술과 예술의 교차점, 실험적 구성 | 회로 패턴, 데이터 시각화 모티프 |
| **GitHub Octocat** | 기술 커뮤니티 상징, 문어+고양이 = 다기능 | 다기능성 표현, 유머와 전문성 공존 |
| **Vercel 로고** | 단순한 삼각형, 정밀함과 속도의 상징 | 기하학적 정밀함, 미니멀 심볼 |
| **VS Code 익스텐션 아이콘들** | 기능별 컬러 코딩, 즉시 인식 가능한 아이콘 | 기능 연상 소품 (렌치, 코드 괄호) |

**전문성 표현 소품 목록**:
- 안테나 (신호 수신/송신 = AI 통신 능력 상징)
- 미니 렌치/스패너 (기술적 문제 해결 능력)
- 회로 기판 패턴 (기술 정체성)
- 헬멧 또는 안전모 (엔지니어링 정체성)
- 코드 괄호 `{}` 장식 (개발 정체성)

---

#### 축 3 — 기술감 (Tech Aesthetics)

| 레퍼런스 | 특징 | 차용 포인트 |
|----------|------|-------------|

| **Low-poly 3D 느낌** | 폴리곤 분할 면 표현 | 몸통 면 분할, 각도 있는 그림자 |

### 2.3 레퍼런스 무드보드 예시 3종

#### 무드보드 1 — "친근한 해커" (슬랙 봇 + 사이버펑크)

```
컨셉: 낮에는 팀의 동료, 밤에는 시스템을 지키는 해커

형태:
  - 기반: Slack Bolt의 단순한 번개/로봇 실루엣
  - 색조: 사이버펑크 네온 블루 (#00D4FF) 윤곽선 글로우
  - 소품: 후드티 + 코딩 키보드 미니어처 들고 있음

  █   │  ● ● ●               │ █
  █   │  SYSTEM: NOMINAL     │ █
  █   └──────────────────────┘ █

#### 무드보드 2 — "귀여운 엔지니어" (카카오 라이언 + 로봇 + 코딩)

```
컨셉: 기술을 이해하지만 항상 밝고 에너지 넘치는 팀원

형태:

  - 알림: 안테나 빙빙 돌아감, 눈 크게, 손 흔들기
  - 축하: 두 팔 번쩍, 안전모에서 종이 폭죽 발사
  - 에러: 안전모 삐딱, 눈에 나선형, 스팸 표정

배경 분위기:
  ╔══════════════════════════════╗
  ║  따뜻한 친근한 분위기        ║
  ║         (◕ᴗ◕)             ║
  ║   {코드 괄호 장식}           ║
  ║   "Let's build together!"    ║
  ╚══════════════════════════════╝

어울리는 UI 컬러: Friendly Neon 후보 B
```

#### 무드보드 3 — "감성 AI" (스타워즈 R2D2 + 고양이)

```
컨셉: 말은 없지만 모든 것을 이해하는, 신뢰할 수 있는 AI 동반자

  - 눈: 단일 원형 렌즈 (카메라 조리개 스타일), 동공 줌인/아웃

  - 에러: 눈 렌즈 회색 어두워짐, 꼬리 처짐, 에러코드 스크린 표시
  - 축하: 눈 렌즈 무지개색, 꼬리 하트 모양, 팡파레 효과

배경 분위기:
  ┌────────────────────────────┐
  │  미니멀리스트 클린 공간     │
  │                            │
  │        [○] ←렌즈 눈        │
  │       /   \                │
  │      |     |  ←원통 몸     │
  │       \ ~ /  ←케이블 꼬리  │
  │  STATUS: OPERATIONAL       │

### 3.1 후보 A — "Cyber Pop" (기술감 우세)

#### 컬러 팔레트

## 4. WCAG 접근성 준수 체크

### 4.1 접근성 기준 개요

WCAG 2.1 기준:
- **AA 레벨**: 일반 텍스트 4.5:1 이상 / 대형 텍스트(18px Bold 이상) 3:1 이상
- **AAA 레벨**: 일반 텍스트 7:1 이상 / 대형 텍스트 4.5:1 이상

### 4.3 색각이상 대응 전략

4. **시뮬레이션 검증**: Figma의 Color Blind 플러그인으로 Deuteranopia/Protanopia 시뮬레이션 필수
