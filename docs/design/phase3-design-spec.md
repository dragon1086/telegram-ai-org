각 봇은 고정 "캐릭터 이모지"를 가지며, 5가지 감정 상태(기본/작업중/완료/오류/대기)를 조합 이모지로 표현한다.

|---|---|---|---|---|---|---|
| **PM봇** `aiorg_pm_bot` | 🎩 지휘자 | 🎩🧑‍💼 | 🎩⚡ | 🎩✅ | 🎩🚨 | 🎩💤 |
| **개발실봇** `aiorg_engineering_bot` | 🔧 장인 | 🔧🧑‍💻 | 🔧⚙️ | 🔧✅ | 🔧💥 | 🔧💤 |
| **디자인실봇** `aiorg_design_bot` | 🎨 아티스트 | 🎨🖌️ | 🎨✨ | 🎨✅ | 🎨😵 | 🎨💤 |
| **기획실봇** `aiorg_product_bot` | 📋 전략가 | 📋🧩 | 📋🔍 | 📋✅ | 📋❗ | 📋💤 |
| **성장실봇** `aiorg_growth_bot` | 📈 탐험가 | 📈🚀 | 📈🔄 | 📈✅ | 📈⚠️ | 📈💤 |
| **운영실봇** `aiorg_ops_bot` | 🛡️ 파수꾼 | 🛡️👁️ | 🛡️🔄 | 🛡️✅ | 🛡️🚨 | 🛡️💤 |
| **리서치봇** `aiorg_research_bot` | 🔬 탐정 | 🔬🕵️ | 🔬💡 | 🔬✅ | 🔬❓ | 🔬💤 |

### 감정 상태 정의

| 상태 | 심볼 | 의미 | 사용 조건 |
|---|---|---|---|
| 기본 (idle) | 캐릭터 단독 | 온라인, 대기 중 | 봇 실행 중이나 태스크 없음 |
| 작업중 (working) | 캐릭터 + 액션 이모지 | 태스크 처리 중 | GoalTracker 태스크 active |
| 완료 (done) | 캐릭터 + ✅ | 태스크 완료 | status=resolved |
| 오류 (error) | 캐릭터 + 🚨/💥/❗ | 에러 발생 | exception / block threshold 초과 |
| 대기 (sleeping) | 캐릭터 + 💤 | 오프라인/중단 | 봇 프로세스 없음 |

## 2. 컬러 시스템 (텔레그램 마크다운 기반)

### 2.1 텔레그램 마크다운 제약 및 전략

텔레그램은 HTML 색상 지정이 불가하므로 **심볼·이모지·포맷팅**으로 의미를 전달한다.

```
굵게:    **텍스트**  → 강조, 헤더
기울임:  _텍스트_   → 보조 설명
코드:    `텍스트`   → 기술값, ID, 수치
코드블록: ```텍스트``` → 상태 카드 전체 레이아웃
```

### 2.2 상태별 심볼 시스템

| 상태 | 기본 심볼 | 확장 심볼 | 의미 |
|---|---|---|---|
| 정상/완료 | ✅ | 🟢 🎉 💚 | Level 1 (성공) |
| 진행중 | 🔄 | ⚙️ ⚡ 🏃 | 작업 실행 중 |
| 경고 | ⚠️ | 🟡 🔶 📢 | Level 2 (주의) |
| 차단/오류 | ❌ | 🔴 🚨 💥 | Level 3 (차단) |
| 대기 | 💤 | ⏸️ 🌙 | 슬립/오프라인 |
| 정보 | ℹ️ | 📌 💬 | 일반 알림 |
| 시작 | 🚀 | ▶️ 🎬 | 작업 시작 |
| 잠금/차단 | 🔒 | 🚧 ⛔ | 배포 게이트 차단 |

### 2.3 WCAG AA 대비율 기준 (tokens.css 연계)

텔레그램 배경(흰색 `#FFFFFF` 또는 다크 `#212121`) 기준:

| 심볼 유형 | 최소 대비율 | 텍스트 크기 | 적용 기준 |
|---|---|---|---|
| 일반 본문 텍스트 | 4.5:1 | < 18pt | WCAG AA Normal |
| 큰 텍스트/헤더 | 3.0:1 | >= 18pt | WCAG AA Large |
| UI 컴포넌트 경계 | 3.0:1 | — | WCAG AA (컴포넌트) |

이모지는 Unicode 표준 렌더링으로 대비율 검증 대상 외. 그러나 **이모지 단독 사용 금지** — 반드시 텍스트 레이블 병기.

## 5. 디자인 토큰 (RETRO-31 연계)

`block_threshold` 값에 따른 severity 3단계 시각 표현. tokens.css `--color-*` 변수와 연계.

### 5.1 Severity 레벨 정의

| 레벨 | 이름 | block_threshold 범위 | 텍스트 색상 토큰 | 이모지 팔레트 |
|---|---|---|---|---|
| **Level 1** | 정상 (Normal) | 0.0 ~ 0.49 | `--color-success: #3fb950` | ✅ 🟢 💚 🎉 👍 |
| **Level 2** | 경고 (Warning) | 0.50 ~ 0.79 | `--color-warning: #d29922` | ⚠️ 🟡 🔶 📢 👀 |
| **Level 3** | 차단 (Block) | 0.80 ~ 1.00 | `--color-danger: #f85149` | ❌ 🔴 🚨 🚧 ⛔ |

### 5.2 WCAG AA 대비율 검증

tokens.css v1.0.0 기준 (배경 `#0d1117` 대비):

| 레벨 | 색상 | 대비율 | WCAG 등급 | 합격 여부 |
|---|---|---|---|---|
| Level 1 (정상) | `#3fb950` | 6.0:1 | AA ✅ | 합격 |
| Level 2 (경고) | `#d29922` | 4.7:1 | AA ✅ | 합격 |
| Level 3 (차단) | `#f85149` | 4.5:1 | AA ✅ | 합격 (경계값) |

텔레그램 라이트 모드 배경 `#FFFFFF` 대비 추가 검증 필요. 이모지는 WCAG 비적용 대상이나 **텍스트 레이블 병기** 원칙 준수.

### 5.3 텔레그램 메시지 내 Severity 표현 패턴

**Level 1 — 정상**
```
✅ **[정상]** pre-flight 체크 통과
🟢 `block_threshold: 0.23` — 배포 허용

모든 기준을 충족했습니다. 진행하세요!
```

**Level 2 — 경고**
```
⚠️ **[경고]** pre-flight 경고 감지
🟡 `block_threshold: 0.65` — 주의 필요

📢 확인 권장 항목:
 • timeout 설정 마진 부족 (현재 95%)
 • 메모리 사용률 높음 (78%)

_배포는 가능하나 모니터링 강화 권장_
```

**Level 3 — 차단**
```
🚨 **[차단]** pre-flight 실패 — 배포 중단
🔴 `block_threshold: 0.92` — 배포 차단

❌ 차단 원인:
 • conftest.py SystemExit(1) 발생
 • 환경 변수 검증 실패: TELEGRAM_TOKEN

⛔ 배포가 자동 차단되었습니다.
👤 @Rocky 에스컬레이션 요청
```

### 5.4 Severity UI 컴포넌트 자동 결정 로직 (RETRO-31)

```python
# block_threshold → severity 매핑 규칙
def get_severity_level(block_threshold: float) -> dict:
    """
    block_threshold 값을 읽어 UI 컴포넌트 severity 레벨 결정.
    RETRO-31: tokens.css --color-* 변수와 연계.
    """
    if block_threshold < 0.50:
        return {
            "level": 1,
            "name": "normal",
            "symbol": "✅",
            "color_token": "--color-success",
            "hex": "#3fb950",
            "emoji_palette": ["✅", "🟢", "💚", "🎉"],
        }
    elif block_threshold < 0.80:
        return {
            "level": 2,
            "name": "warning",
            "symbol": "⚠️",
            "color_token": "--color-warning",
            "hex": "#d29922",
            "emoji_palette": ["⚠️", "🟡", "🔶", "📢"],
        }
    else:
        return {
            "level": 3,
            "name": "block",
            "symbol": "❌",
            "color_token": "--color-danger",
            "hex": "#f85149",
            "emoji_palette": ["❌", "🔴", "🚨", "⛔"],
        }
```

### 5.5 접근성 가이드라인 (RETRO-32 연계)

| Severity | 색상 | 이모지 | 텍스트 패턴 | 아이콘 의미 |
|---|---|---|---|---|
