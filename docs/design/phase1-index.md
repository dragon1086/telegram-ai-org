## 핵심 결정 사항 요약

### 1. 대시보드 정보 구조 (Priority 순)

```
P1 — 티켓 현황 패널    : 활성 태스크 · 상태 분류 · 긴급 알림
P2 — 완료 작업 패널    : 오늘 완료 타임라인 · 조직별 기여도 · 완료율
P3 — 원격 접근 패널    : ngrok 상태 · QR코드 · 헬스체크
```

### 2. 컬러 시스템 — 후보 B "Friendly Neon" 권고

| 역할 | 색상 | HEX | 근거 |
|------|------|-----|------|
| 주색 | 바이올렛 | `#7C4DFF` | 기술감 + 친근함 균형 |
| 보조색 | 민트 그린 | `#69F0AE` | 완료/성공 시각화 |
| 배경 | 미드나잇 | `#1A1A2E` | 야간 작업 피로도 최소화 |
| 알림 | 사이버 블루 | `#00D4FF` | WCAG AA 5.8:1 대비율 |

### 3. 마스코트 "봇키(Botki)" 핵심 사양

- **형태**: 고양이귀 달린 소형 로봇, 둥근 LED 눈, 안테나 상태 표시
- **감정 상태 6종**: IDLE · WORKING · ALERT · ERROR · CELEBRATE · SLEEP
- **핵심 접근성**: 색상 외 형태 변화 병행, `prefers-reduced-motion` 대응

### 4. 로고 시스템

| 용도 | 컨셉 | 설명 |
|------|------|------|
| 주력 (헤더·README·봇 프로필) | **Circuit Bot (A)** | 심볼+워드마크, 다크/라이트 2종 |
| 보조 (파비콘·배지·문서) | **Minimal Mark (B)** | 단색 미니멀, 16px~512px |

## WCAG 2.1 접근성 준수 현황

| 항목 | 기준 | 현황 |
|------|------|------|
| 텍스트 대비율 (일반) | AA 4.5:1 | ✅ 최소 5.8:1 |
| 텍스트 대비율 (대형) | AA 3:1 | ✅ 전 항목 통과 |
| 로고 대비율 | AA 3:1 | ✅ 최소 10.2:1 (AAA) |
| 마스코트 대체 텍스트 | 필수 | ✅ aria-label 명세 포함 |
| 애니메이션 접근성 | 권고 | ✅ prefers-reduced-motion 가이드 포함 |
| 색상 외 보조 표현 | AA 권고 | ✅ 형태·텍스트 병행 명세 |

## Phase 2 — 프로토타입 권고사항

### 즉시 착수 가능 항목 (Phase 1 산출물 기반)

1. **컬러 토큰 CSS 변수화**
   ```css
   --color-primary: #7C4DFF;
   --color-success: #69F0AE;
   --color-alert: #00D4FF;
   --color-bg: #1A1A2E;
   ```

2. **마스코트 SVG 에셋 제작** — phase1-character-concept.md 형태 묘사 → SVG 6종 (상태별)

3. **대시보드 HTML/CSS 프로토타입** — phase1-wireframe.md ASCII 레이아웃 → 실제 구현
   - 3패널 CSS Grid 레이아웃
   - SSE 연결 상태 표시 컴포넌트
   - 마스코트 플로팅 버블 (position: fixed)

4. **로고 SVG 2종** — phase1-logo-guideline.md 컨셉 A/B → 실제 SVG 파일 생성

| 대시보드 3패널 레이아웃 | 중간 | 최고 | **P0** |

## 디자인 원칙 (Phase 1 확립)

1. **친근함 우선** — 기술 조직이지만 매일 보는 도구, 피로감 최소화
2. **상태 기반 UI** — 마스코트·색상·아이콘이 모두 시스템 상태를 반영
3. **접근성 비타협** — WCAG 2.1 AA는 최소선, 가능한 AAA 달성
4. **일관성 유지** — 컬러 토큰 · 로고 가이드라인으로 컴포넌트 확장 시 브랜드 정체성 보존
